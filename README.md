# maiayoutube-site

Site público do app OAuth **maiayoutube** (projeto `antaresmaia` no Google Cloud): página inicial e política de privacidade, exigidas pelo Google para publicar o app em produção.

- Página inicial: https://mayaemerson.github.io/maiayoutube-site/
- Política de privacidade: https://mayaemerson.github.io/maiayoutube-site/privacidade.html

Hospedado no GitHub Pages (branch `main`, raiz). HTML puro, sem dependências.

**Este repositório é público.** Ele contém só estas páginas: nenhuma credencial, nenhum dado do canal e nenhum código do projeto principal.
