Política de Privacidade

Aplicativo maiayoutube · Vigente desde 17 de novembro de 2026

Esta política explica como o aplicativo maiayoutube acessa, usa, armazena e compartilha dados obtidos pelos serviços de API do YouTube. O aplicativo é de uso pessoal e acessa apenas o canal do próprio desenvolvedor.

1. Serviços de API do YouTube

O maiayoutube usa os serviços de API do YouTube (YouTube Data API v3 e YouTube Analytics API). Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

2. Dados acessados

Com a autorização dada na tela de consentimento do Google, o aplicativo acessa:

  • informações básicas do canal (nome e identificador);
  • a lista de vídeos do canal e seus metadados (título, descrição, tags, miniatura, status e data de publicação);
  • métricas de desempenho do canal (visualizações, tempo de exibição, inscritos e indicadores semelhantes);
  • a permissão de enviar vídeos e editar os metadados dos vídeos do próprio canal.

3. Como os dados são usados

Os dados são usados apenas para enviar e agendar vídeos do canal, atualizar seus metadados e gerar relatórios internos de desempenho que orientam a produção de novos vídeos. Os dados não são usados para publicidade, nem vendidos, nem usados para traçar perfis de pessoas.

4. Armazenamento

O aplicativo roda no computador do próprio desenvolvedor. As credenciais de acesso (tokens OAuth) e os relatórios gerados ficam guardados localmente nesse computador e não são enviados a servidores de terceiros. Não há banco de dados externo.

5. Compartilhamento

Os dados obtidos pela API do YouTube não são compartilhados com terceiros. O aplicativo se comunica apenas com os servidores do Google, necessários para o funcionamento da API.

6. Cookies

O aplicativo não usa cookies nem tecnologias de rastreamento. Este site também não usa cookies.

7. Retenção e exclusão

Os dados ficam guardados enquanto o aplicativo estiver em uso. Para excluí-los, basta apagar a pasta de dados local do aplicativo. Os dados da API armazenados localmente são atualizados ou apagados em até 30 dias, conforme as políticas para desenvolvedores dos serviços de API do YouTube.

8. Como revogar o acesso

Você pode revogar a qualquer momento o acesso do aplicativo à sua conta Google na página de permissões de segurança da Conta do Google.

9. Alterações nesta política

Se esta política mudar, a nova versão será publicada nesta página com a data de vigência atualizada.

10. Contato

Dúvidas sobre esta política podem ser enviadas pelo e-mail de suporte informado na tela de consentimento do aplicativo ou abrindo uma solicitação no repositório do site.
